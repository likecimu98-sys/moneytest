2.3. Технические данные: Сервис хранит рабочие данные в памяти вашего браузера (localStorage). Сервис не использует рекламные cookie, счётчики посещаемости и сторонние трекеры.

4. Где и как хранятся данные

4.1. По умолчанию все данные хранятся локально в браузере пользователя и никуда не передаются.

4.2. Если пользователь включает онлайн-синхронизацию, копия его данных передаётся по защищённому соединению (HTTPS) и сохраняется на сервере, расположенном на территории Российской Федерации.

4.3. Доступ к данным аккаунта возможен только по ключу синхронизации, известному пользователю. Страница «кабинета родителя» содержит только сведения о конкретном ученике (без финансовых итогов репетитора и данных других учеников) и доступна только по секретной ссылке; пользователь может в любой момент отключить кабинет или заменить ссылку.

4.4. Данные хранятся, пока пользователь пользуется Сервисом. Пользователь может в любой момент удалить свои данные средствами Сервиса (очистка данных, отключение синхронизации) либо запросить удаление серверной копии по e-mail Оператора — удаление выполняется в срок не более 10 рабочих дней.

Оператор предоставляет пользователю технические средства и обрабатывает эти данные только по его поручению.
